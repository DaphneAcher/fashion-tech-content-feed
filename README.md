# Fashion-Tech Content Feed 🧵

This is a slow-build side project where I'm experimenting with the intersection of fashion, content platforms, and web tech. The goal is to build a dynamic content feed (inspired by platforms like Substack and Pinterest) that pulls in posts via APIs and displays them with clean, minimal design.

Right now, I'm starting small — focusing on API integration, content layout, and early UI ideas. Over time, this may evolve into something smarter with filtering, recommendations, or even AI-assisted styling.

This repo documents that process as I go.
